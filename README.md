# lcd-lab-William
LCD display project for IoT lab
Reaction game

This code is for a simple reaction game involving one push button and an LCD monitor

It innitialy presents a prompt to Prepare yourself and then after a random delay the player is prompted to press the push button, the game then uses the recorded reaction time and displays it to the player.
